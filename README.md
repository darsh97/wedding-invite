# Arunkumar & Jayashree

An interactive wedding invitation built as a personal gift. It includes a reveal experience, live countdown, event details, Google Calendar links, venue directions, a photo story, and a playful blessing interaction.

## Local development

```bash
npm install
npm run dev
```

Production checks:

```bash
npm run lint
npm run build
```

## Netlify

Connect this repository to Netlify. The included `netlify.toml` configures the build command and publish directory automatically.
